# Request for Startups: Perú (RFS-Perú) 🇵🇪🚀

> **Auditoría de problemas estructurales del Perú descompuestos por primeros principios y traducidos a oportunidades de negocio para fundadores de tecnología.**

---

## 🎯 Por Qué Existe Este Repositorio

En el ecosistema tradicional peruano abundan dos actitudes estériles:
1. **El lamento improductivo:** La queja constante en redes sociales sobre la informalidad, la corrupción, el tráfico y la inseguridad, esperando que un político o una ley venga a resolverlo.
2. **La copia ciega de Silicon Valley:** Startups locales intentando replicar apps para el 1% de Lima Top (otro delivery de café de especialidad, otro SaaS para directorios de San Isidro) ignorando que el 71% de la economía real está rota y desatendida.

Este repositorio es una base de datos abierta para **ingenieros, científicos, diseñadores y operadores** que quieren construir empresas de tecnología que ataquen problemas reales con ventajas asimétricas.

---

## 🔬 Metodología: Primeros Principios

Cada problema en este repositorio se audita bajo el [Framework de 5 Capas](framework/first_principles_methodology.md):

$$\text{Síntoma Visible} \longrightarrow \text{Física y Datos} \longrightarrow \text{Por Qué Falla el Sistema} \longrightarrow \text{Primeros Principios} \longrightarrow \text{Request for Startups (RFS)}$$

## 🤝 Cómo Contribuir

1. **Abre un Issue** proponiendo un dolor estructural de Perú que aún no esté mapeado.
2. Utiliza la [plantilla de descomposición por primeros principios](framework/first_principles_methodology.md) para enviar un Pull Request con datos verificables.
3. Este repositorio es **Open Source (MIT)**. Puedes usar cualquiera de estas tesis para fundar una empresa, armar tu pitch deck o validar tu producto. No necesitas pedir permiso.
